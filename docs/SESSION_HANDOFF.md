# Journey Session Handoff Template

Copy this template into the final message of a long Codex session. Update the repository documents when the change is durable; this template supplements them and does not replace them.

```markdown
## Journey handoff

Repository: ~/personal/journey
Branch: <current branch>
Commit: <latest relevant commit>
Milestone: <roadmap phase and task>

### Goal of this session

<one concrete outcome>

### Completed

- <observable result>

### Files changed

- `<path>` — <responsibility>

### Verification

- `<command>` — <result>

### Durable decisions

- <decision and reason; also update docs/PROJECT_CONTEXT.md>

### Open risks or blockers

- <specific risk, evidence, and required resolution>

### Exact next action

1. <the first command or edit the next session should perform>

### Read before continuing

- `AGENTS.md`
- `docs/PROJECT_CONTEXT.md`
- `docs/ROADMAP.md`
- <feature-specific spec or plan>
```

Do not include secrets, access tokens, private browsing data, or unsupported game facts.
